# Personal Portfolio Website - Next.js

My personal portfolio website to showcase my skills, projects, education, and experience. Built with Next.js and TypeScript.

## Live Demo
👉 [Click here to view my portfolio](https://my-portfolio-mu-roan-32.vercel.app/)

## Sections
- Home - Introduction and hero section
- About Me - My background and education
- Skills - Technologies I work with
- Projects - My best projects with GitHub links
- Contact - How to reach me

## Features
- Built with Next.js App Router
- Type-safe code with TypeScript
- Fully responsive design for mobile and desktop
- Clean and modern UI
- Projects section with github links
- Fast performance with Next.js optimization

## Technologies Used
- Next.js
- TypeScript
- React.js
- CSS 
- Vercel for deployment
